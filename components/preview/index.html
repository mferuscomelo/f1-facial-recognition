F1 FaceCam: live view

Webcam on the SG Wireless F1. Edge Impulse models on the board find faces and recognise the people you register below. The dashed square is what the face finder sees.

People

    Register: stand about 50 cm from the webcam, alone, in good light. The F1 takes 5 pictures (about 15 s). Recognition only runs while at least one person is registered.

    Collect training images

    0 images

    Saves camera frames in this browser (not on the F1), with the F1's face boxes in info.labels. Upload all the unzipped files in Edge Impulse under Data acquisition → Add data → Upload data, check the boxes, retrain. Frames with nobody in them teach the model what is not a face.

    Firmware

    –

    New model from Edge Impulse? Put the export in the project, run pio run and upload .pio/build/f1/firmware.bin here. If the new firmware does not start properly, the F1 goes back to this one.
